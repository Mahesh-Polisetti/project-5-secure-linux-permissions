# Project 5: Secure Linux Server Permissions

## Objective
Implement user-based access control in Linux using users, groups, directory ownership, and permissions.

## Implementation
- Created developers and testers groups.
- Created devuser, testuser, and guestuser.
- Assigned users to appropriate groups.
- Created separate secure directories.
- Configured ownership using chown.
- Applied permissions using chmod 2770.
- Tested authorized and unauthorized access.

## Tools Used
- Linux
- Bash
- chmod
- chown
- useradd
- groupadd
- usermod.

## Result
Successfully implemented Linux directory access restrictions and verified permission-based access control.
